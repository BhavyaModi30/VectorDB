# VectorDB
It is the VectorDB Project repository by Team Negative.

# Running Guidlines
To run the base test for the Recall@k value follow these steps
1. Make a build directory and include the data sift files from /data.
2. In the build directory run the following commands.
```bash
cmake ..
cmake --build .
./main
```

Expected Output : "Recall@100: 1"
